## Подключение

```jsx
import { CalendarMonthPicker } from '@alfalab/core-components/calendar';
import { CalendarMonthPickerDesktop } from '@alfalab/core-components/calendar/desktop';
import { CalendarMonthPickerMobile } from '@alfalab/core-components/calendar/mobile';
```

Из индекса импортируется responsive версия компонента.

## Значение

`value` — timestamp любого дня месяца. В `onChange` приходит timestamp первого дня выбранного месяца
(`00:00` по локальному времени), при сбросе в мобильной версии — `undefined`.
`onChange` вызывается только при клике по месяцу. Смена года в селекте значение не меняет.

## Использование dataTestId

В компоненте используются модификаторы для `dataTestId`:

```jsx
// desktop
{
    picker: dataTestId,
    btnYear: `${dataTestId}-btn-year`,
};

// mobile
{
    modal: dataTestId,
    picker: `${dataTestId}-calendar`,
    btnApply: `${dataTestId}-btn-apply`,
    btnReset: `${dataTestId}-btn-reset`,
    btnCancel: `${dataTestId}-btn-cancel`,
};
```
